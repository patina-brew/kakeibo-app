# 家計簿アプリ

支出・収入を登録し、カレンダーでの確認と月別・年度別の集計ができる個人用の家計簿アプリです。

## 構成

- `client/`: Vue + TypeScript + Vite(画面)
- `server/`: Node.js + Express + TypeScript(API)、データは SQLite(`server/data/kakeibo.db`)に保存
- `openspec/`: 仕様・設計・タスク(OpenSpec)

## 必要なもの

- Node.js 20.19 以上

## 初回セットアップ

```cmd
cd server
npm install
cd ..\client
npm install
```

## 起動

ターミナルを2つ開きます。

サーバー(`http://localhost:3000`):

```cmd
cd server
npm run dev
```

クライアント(`http://localhost:5173`):

```cmd
cd client
npm run dev
```

ブラウザで `http://localhost:5173` を開きます。`/api` へのリクエストはサーバーに転送されます。

## テスト・ビルド

```cmd
cd server
npm test
npm run build

cd ..\client
npm test
npm run build
```

## 機能・仕様

- 収入・支出の登録、編集、削除
  - 入力項目は、日付(カレンダーで選択)、種別(収入/支出)、金額(1以上の整数)、カテゴリです。
  - 曜日は日付から自動で表示します(保存はしません)。
- カレンダー画面
  - 日付を選択すると、その日に登録済みの収入・支出を表示します。
  - 登録・編集・削除は、この画面で選択した日付を基準に行います。
- カテゴリ管理
  - 収入用・支出用それぞれに初期カテゴリがあり、追加・変更・削除ができます。
  - 取引で使用中のカテゴリは削除できません。
  - 一度削除した初期カテゴリは、再起動しても復活しません。
- 集計画面
  - 月別・年度別の、収入合計・支出合計・差額(収入 − 支出)を表示します。
  - 年度は4月始まり(4月〜翌年3月)です。
- 日付は `YYYY-MM-DD` 形式で扱い、タイムゾーン変換はしません。

## 使い方

1. 上記の手順でサーバーとクライアントを起動し、`http://localhost:5173` を開きます。
2. カレンダーで日付を選び、「新規登録」から収入・支出を入力します。
3. 選択した日の一覧から、編集・削除ができます。削除時は確認が表示されます。
4. 「集計」ページで月別・年度別の合計と差額を確認します。
5. カテゴリは、カレンダー画面の「カテゴリ管理」から追加・変更・削除します。

## データ

- データは `server/data/kakeibo.db`(SQLite)に保存されます。このフォルダーは Git 管理外です。
- バックアップは、このファイルをコピーしてください。
- 保存先は環境変数 `DB_PATH`、サーバーのポートは `PORT` で変更できます。

## セキュリティ上の注意・脆弱性

- **認証はありません。** サーバーは `127.0.0.1` のみで待ち受けます。個人のパソコン内で使う前提であり、インターネットや社内ネットワークへ公開しないでください。
- 公開する場合は、認証、HTTPS、アクセス制限を別途追加する必要があります。
- **依存パッケージの脆弱性:** 2026-10-28 に対応済みです。`server` の `vitest` を 5.0.5、`vite` を 8.3.5 に更新し、`npm audit` で 0 件になったことを確認しました。`client` も 0 件です。
- 依存パッケージを更新したときは、`npm audit` を再実行して状況を確認してください。
