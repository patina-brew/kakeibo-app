# Spec Delta

## Purpose

月別・年度別に、支出合計・収入合計・差額を確認できる集計ページを提供し、家計の収支状況を把握できるようにする。

## ADDED Requirements

### Requirement: 月別集計
システムは、指定した年月について、支出合計、収入合計、差額(収入合計 − 支出合計)を表示する集計ページを提供しなければならない(SHALL)。

#### Scenario: 月の合計を表示する
- **WHEN** 2026年10月に、支出が合計30,000円、収入が合計250,000円登録されている状態で、2026年10月の集計を表示する
- **THEN** 支出合計30,000円、収入合計250,000円、差額220,000円が表示される

#### Scenario: 収支がマイナスの月
- **WHEN** 支出合計が収入合計を上回る月の集計を表示する
- **THEN** 差額が負の値で表示され、プラスの場合と区別できる

#### Scenario: 収支がない月
- **WHEN** 収支が登録されていない月の集計を表示する
- **THEN** 支出合計、収入合計、差額がすべて0円で表示される

### Requirement: 年度別集計
システムは、年度(4月〜翌年3月)ごとに、支出合計、収入合計、差額を表示しなければならない(SHALL)。年度は開始年で表す(例: 2026年度は2026年4月〜2027年3月)。

#### Scenario: 年度の境界
- **WHEN** 2027年3月31日の収支と2027年4月1日の収支を登録し、年度別集計を表示する
- **THEN** 2027年3月31日の収支は2026年度に、2027年4月1日の収支は2027年度に集計される

#### Scenario: 年度内の月別内訳
- **WHEN** 年度別集計で年度を選択する
- **THEN** その年度の4月から翌年3月までの月ごとの支出合計、収入合計、差額が表示される

### Requirement: 集計対象の切り替え
システムは、集計ページで、月と年度を切り替えて表示できなければならない(SHALL)。

#### Scenario: 前の月を表示する
- **WHEN** 月別集計で「前の月」を操作する
- **THEN** 前月の集計が表示される

#### Scenario: 年度を切り替える
- **WHEN** 年度別集計で別の年度を選択する
- **THEN** 選択した年度の集計が表示される

### Requirement: 集計への即時反映
システムは、収支の登録・編集・削除の結果を、集計ページの表示に反映しなければならない(SHALL)。

#### Scenario: 登録後に集計が変わる
- **WHEN** 当月の支出を1件登録したあと、当月の集計ページを表示する
- **THEN** 支出合計と差額に、登録した金額が反映されている
