# Spec Delta

## Purpose

月別・年別に、支出合計・収入合計・差額を確認できる集計ページを提供し、家計の収支状況を把握できるようにする。カテゴリ別の内訳と収支の割合を円グラフで視覚化する。

## ADDED Requirements

### Requirement: 月別集計
システムは、指定した年月について、支出合計、収入合計、差額(収入合計 − 支出合計)を表示する集計ページを提供しなければならない(SHALL)。

#### Scenario: 月の合計を表示する
- **WHEN** 2026年10月に、支出が合計30,000円、収入が合計250,000円登録されている状態で、2026年10月の集計を表示する
- **THEN** 支出合計30,000円、収入合計250,000円、差額220,000円が表示される

#### Scenario: 収支がマイナスの月
- **WHEN** 支出合計が収入合計を上回る月の集計を表示する
- **THEN** 差額が負の値で表示され、プラスの場合と区別できる

#### Scenario: 収支がない月
- **WHEN** 収支が登録されていない月の集計を表示する
- **THEN** 支出合計、収入合計、差額がすべて0円で表示される

### Requirement: 年別集計
システムは、年(1月〜12月)ごとに、支出合計、収入合計、差額を表示しなければならない(SHALL)。

#### Scenario: 年の境界
- **WHEN** 2026年12月31日の収支と2027年1月1日の収支を登録し、年別集計を表示する
- **THEN** 2026年12月31日の収支は2026年に、2027年1月1日の収支は2027年に集計される

#### Scenario: 年内の月別内訳
- **WHEN** 年別集計で年を選択する
- **THEN** その年の1月から12月までの月ごとの支出合計、収入合計、差額が表示される

### Requirement: カテゴリ別内訳の円グラフ
システムは、集計ページに、支出と収入それぞれのカテゴリ別内訳を円グラフで表示しなければならない(SHALL)。支出はオレンジ系、収入は青系の色で統一し、金額の多いカテゴリほど濃い色で表示しなければならない(SHALL)。凡例にはカテゴリ名・金額・割合(%)を表示しなければならない(SHALL)。

#### Scenario: カテゴリ別の内訳が表示される
- **WHEN** 支出が「食費」20,000円と「交通費」10,000円登録されている月の集計を表示する
- **THEN** 支出の内訳グラフに「食費 20,000円 66.7%」「交通費 10,000円 33.3%」が金額の多い順に表示される

#### Scenario: データがない期間
- **WHEN** 収支が登録されていない期間の集計を表示する
- **THEN** 円グラフは「データがありません」と表示される

### Requirement: 収支の割合グラフ
システムは、収入と支出の両方が登録されている期間に限り、合計に対する収入と支出の割合を1つの円グラフで表示しなければならない(SHALL)。収入は青、支出はオレンジで表示しなければならない(SHALL)。

#### Scenario: 収入と支出の両方がある期間
- **WHEN** 収入250,000円と支出30,000円が登録されている月の集計を表示する
- **THEN** 収支の割合グラフに、収入(青)と支出(オレンジ)の割合が表示される

#### Scenario: 片方しかない期間
- **WHEN** 収入または支出のどちらか一方のみが登録されている期間の集計を表示する
- **THEN** 収支の割合グラフは表示されない

### Requirement: 集計対象の切り替え
システムは、集計ページで、月と年を切り替えて表示できなければならない(SHALL)。

#### Scenario: 前の月を表示する
- **WHEN** 月別集計で「前の月」を操作する
- **THEN** 前月の集計が表示される

#### Scenario: 年を切り替える
- **WHEN** 年別集計で別の年を選択する
- **THEN** 選択した年の集計が表示される

### Requirement: 集計への即時反映
システムは、収支の登録・編集・削除の結果を、集計ページの表示に反映しなければならない(SHALL)。

#### Scenario: 登録後に集計が変わる
- **WHEN** 当月の支出を1件登録したあと、当月の集計ページを表示する
- **THEN** 支出合計と差額に、登録した金額が反映されている
