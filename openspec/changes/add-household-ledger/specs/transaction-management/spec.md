# Spec Delta

## Purpose

支出・収入を日付・金額・カテゴリ付きで記録し、登録・編集・削除できるようにする。家計簿の基礎となるデータ管理の振る舞いを定める。

## ADDED Requirements

### Requirement: 収支の登録
システムは、収支の種別(支出または収入)、日付(年月日)、金額、カテゴリを指定して収支を新規登録できなければならない(SHALL)。

#### Scenario: 支出を登録する
- **WHEN** 種別「支出」、日付「2026-10-26」、金額「1200」、カテゴリ「食費」を指定して登録する
- **THEN** 収支が保存され、同じ内容で参照できる

#### Scenario: 収入を登録する
- **WHEN** 種別「収入」、日付、金額、カテゴリを指定して登録する
- **THEN** 収支が収入として保存される

### Requirement: 入力値の検証
システムは、金額を1以上の整数(円)とし、種別・日付・カテゴリを必須として検証しなければならない(SHALL)。

#### Scenario: 金額が不正
- **WHEN** 金額が0、負数、または整数でない値で登録しようとする
- **THEN** 登録は拒否され、エラーが表示される

#### Scenario: 必須項目の未入力
- **WHEN** 日付またはカテゴリが未指定で登録しようとする
- **THEN** 登録は拒否され、未入力の項目が示される

### Requirement: 曜日の表示
システムは、日付から算出した曜日を、収支とあわせて表示しなければならない(SHALL)。曜日は入力させない。

#### Scenario: 曜日が自動表示される
- **WHEN** 日付「2026-10-26」の収支を表示する
- **THEN** 曜日「月」が併せて表示される

### Requirement: 収支の編集
システムは、登録済みの収支の種別・日付・金額・カテゴリを変更できなければならない(SHALL)。

#### Scenario: 金額を編集する
- **WHEN** 登録済みの収支の金額を変更して保存する
- **THEN** 変更後の金額が保存され、一覧・集計に反映される

#### Scenario: 日付を編集する
- **WHEN** 登録済みの収支の日付を別の日に変更して保存する
- **THEN** 収支は新しい日付の収支として扱われる

### Requirement: 収支の削除
システムは、削除の確認を行ったうえで、登録済みの収支を削除できなければならない(SHALL)。

#### Scenario: 削除を確定する
- **WHEN** 収支の削除を実行し、確認で承諾する
- **THEN** 収支が削除され、一覧・集計に表示されなくなる

#### Scenario: 削除を取り消す
- **WHEN** 収支の削除を実行し、確認でキャンセルする
- **THEN** 収支は削除されない

### Requirement: データの永続化
システムは、登録した収支を、アプリを閉じて再度開いても保持しなければならない(SHALL)。

#### Scenario: 再起動後も保持される
- **WHEN** 収支を登録したあと、アプリとサーバーを再起動する
- **THEN** 登録した収支が引き続き表示される
