# Spec Delta

## Purpose

カレンダーで日付を選び、その日の収支の確認と、登録・編集・削除をおこなえるようにする。

## ADDED Requirements

### Requirement: カレンダーでの日付選択
システムは、月単位のカレンダーを表示し、ユーザーが日付を選択できなければならない(SHALL)。月は前後に切り替えられなければならない(SHALL)。

#### Scenario: 日付を選択する
- **WHEN** カレンダー上の日付をクリックする
- **THEN** その日付が選択状態として強調表示される

#### Scenario: 月を切り替える
- **WHEN** 「次の月」を操作する
- **THEN** 翌月のカレンダーが表示される

### Requirement: 選択日の収支表示
システムは、日付を選択したとき、その日に登録済みの支出・収入を、種別・金額・カテゴリ付きで一覧表示しなければならない(SHALL)。

#### Scenario: 登録済みの収支がある日
- **WHEN** 収支が登録されている日付を選択する
- **THEN** その日の支出・収入が一覧で表示される

#### Scenario: 収支がない日
- **WHEN** 収支が登録されていない日付を選択する
- **THEN** 「登録された収支はありません」と表示される

### Requirement: 登録・編集時の日付
システムは、収支の新規登録・編集時に、カレンダー画面で選択中の日付を日付として使わなければならない(SHALL)。登録・編集のダイアログ内にカレンダーは表示せず、日付は曜日付きの表示のみとしなければならない(SHALL)。日付を変えたい場合は、先にカレンダー画面で日付を選び直す。

#### Scenario: 選択日を初期値にして登録する
- **WHEN** カレンダーで日付を選択した状態で新規登録を開始する
- **THEN** 選択した日付が曜日付きで表示され、その日付で登録される

#### Scenario: ダイアログにカレンダーが表示されない
- **WHEN** 新規登録または編集のダイアログを開く
- **THEN** ダイアログ内にカレンダーは表示されず、日付の表示のみがある

### Requirement: 日付ごとの収支有無の表示
システムは、カレンダー上で、収支が登録されている日付を、登録のない日付と区別できるよう表示しなければならない(SHALL)。印は種別ごとに色分けし、支出はオレンジ、収入は青で表示しなければならない(SHALL)。支出と収入の両方が登録されている日付には、両方の色の印を表示しなければならない(SHALL)。

#### Scenario: 支出のみ登録された日
- **WHEN** 支出のみが登録された日付を含む月を表示する
- **THEN** その日付にオレンジの印のみが表示される

#### Scenario: 支出と収入の両方が登録された日
- **WHEN** 支出と収入の両方が登録された日付を含む月を表示する
- **THEN** その日付にオレンジと青の印が両方表示される

### Requirement: 選択日からの操作
システムは、選択日の一覧から、収支の新規登録・編集・削除を開始できなければならない(SHALL)。操作の完了後は、一覧とカレンダーの表示を更新しなければならない(SHALL)。

#### Scenario: 削除後に表示が更新される
- **WHEN** 選択日の一覧で最後の1件を削除する
- **THEN** 一覧は空表示になり、カレンダーの印も消える
