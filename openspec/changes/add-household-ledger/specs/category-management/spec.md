# Spec Delta

## Purpose

収支に付与するカテゴリを、初期カテゴリの提供とユーザーによる追加・編集で管理できるようにする。

## ADDED Requirements

### Requirement: 初期カテゴリの提供
システムは、初回利用時から、支出用と収入用の初期カテゴリを選択可能な状態で提供しなければならない(SHALL)。

#### Scenario: 初期カテゴリが選べる
- **WHEN** 初めて収支登録画面で種別「支出」を選ぶ
- **THEN** 「食費」「日用品」「交通費」などの初期の支出カテゴリが選択肢に表示される

#### Scenario: 種別ごとに選択肢が分かれる
- **WHEN** 種別を「収入」に切り替える
- **THEN** 「給与」などの収入用カテゴリのみが選択肢に表示される

### Requirement: カテゴリの追加
システムは、ユーザーが種別(支出または収入)を指定して、新しいカテゴリを追加できなければならない(SHALL)。同じ種別内でカテゴリ名は重複してはならない(MUST NOT)。

#### Scenario: カテゴリを追加する
- **WHEN** 種別「支出」でカテゴリ名「趣味」を追加する
- **THEN** 「趣味」が支出カテゴリの選択肢に表示される

#### Scenario: 重複する名前
- **WHEN** 同じ種別にすでに存在するカテゴリ名を追加しようとする
- **THEN** 追加は拒否され、エラーが表示される

### Requirement: カテゴリの編集
システムは、カテゴリ名を変更できなければならない(SHALL)。変更は、そのカテゴリが付いた既存の収支にも反映されなければならない(SHALL)。

#### Scenario: カテゴリ名を変更する
- **WHEN** カテゴリ「食費」を「食事」に変更する
- **THEN** 「食費」が付いていた既存の収支は、「食事」として表示される

### Requirement: 使用中カテゴリの削除制限
システムは、収支で使用中のカテゴリを削除してはならない(MUST NOT)。

#### Scenario: 使用中のカテゴリを削除しようとする
- **WHEN** 収支が1件以上登録されているカテゴリの削除を実行する
- **THEN** 削除は拒否され、使用中であることが表示される

#### Scenario: 未使用のカテゴリを削除する
- **WHEN** 収支が1件もないカテゴリの削除を実行し、確認で承諾する
- **THEN** カテゴリが削除され、選択肢に表示されなくなる
