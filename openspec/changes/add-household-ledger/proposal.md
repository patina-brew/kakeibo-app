# Proposal

## Why

家計簿アプリが未実装のため、日々の支出・収入を記録し、月別・年度別に収支を把握する基本機能を一式用意する。まず最小限の使える家計簿として、登録・閲覧・集計を揃える。

## What Changes

- 支出・収入を「日付(年月日)・曜日・金額・カテゴリ」付きで登録できる(曜日は日付から自動算出)
- 登録した収支の編集・削除ができる
- 登録・編集時はカレンダーで日付を選択できる
- カレンダーで日付を選択すると、その日に登録済みの支出・収入の一覧を表示する
- 月別・年度別(4月〜翌3月)の支出合計・収入合計・差額を表示する集計ページを追加する
- カテゴリは初期カテゴリを用意し、ユーザーが追加・編集できる
- 技術構成: Vue + TypeScript + Vite のフロントエンドと、SQLite を使うサーバー(API)を新規構築する

### 対象外

- ユーザー認証・複数ユーザー対応
- 予算管理、グラフ表示、CSV入出力
- 繰り返し(定期)収支、通貨の切り替え
- スマホ向けネイティブアプリ

## Capabilities

### New Capabilities
- `transaction-management`: 支出・収入の登録・編集・削除と、日付・曜日・金額・カテゴリの保持
- `category-management`: 初期カテゴリの提供と、ユーザーによるカテゴリの追加・編集
- `calendar-view`: カレンダーでの日付選択と、選択日の登録済み収支の表示
- `summary-report`: 月別・年度別の支出合計・収入合計・差額の集計表示

### Modified Capabilities

なし(既存の仕様はない)

## Impact

- 新規コード: フロントエンド(Vue + TypeScript + Vite)、サーバー API、SQLite のスキーマ
- 新規依存: Vue、Vite、TypeScript、SQLite ドライバ、サーバーフレームワーク、カレンダー用コンポーネント
- 既存コードへの影響はなし(リポジトリは新規状態)
